# 프로젝트 후보 카드

> 1주차에는 후보를 정하고, 3주차에 실제 데이터를 확인한 뒤 최종 확정한다.

- 프로젝트 후보 이름:
- 사용자는 누구인가?
- 사용자가 입력하는 것은 무엇인가?
- 서비스가 예측·분류할 것은 무엇인가?
- 결과를 어떤 화면으로 보여줄까?
- 성공을 어떤 숫자로 확인할까?
- 사용할 수 있는 데이터 후보와 출처:
- 개인정보·저작권·편향 위험:
- 3주차에 반드시 확인할 것:
- 예시 주제 번호와 이름:
- 선정 점수(10점 만점):

## 주제 확인

- [ ] 사람의 채용·신용·질병·범죄 같은 고위험 결정을 자동화하지 않는다.
- [ ] 사용 허가를 확인할 수 있는 데이터 후보가 있다.
- [ ] 15주 안에 최소 기능을 배포할 수 있는 범위다.
